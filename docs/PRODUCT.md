# Producto

CentroColor será una aplicación operativa para un negocio de fotografía, marquetería y venta de productos. Gradualmente gestionará ventas, productos, stock, clientes, trabajos fotográficos, marquetería, turnos, sesiones, eventos, alquiler de recursos y equipamiento, presupuestos y pagos.

Los Sprints 1 y 2 entregan la fundación técnica y la identidad estructural de negocio, sucursal y dispositivo. Sprint 3 incorpora autenticación y autorización. Sprint 4 incorpora Clientes en Web y Desktop; su sincronización bidireccional ya existe. Sprint 5 incorpora POS MVP Desktop para cargar productos durante ventas y cobrar offline. Sprint 6 agrega ProductCategory/Product y Sale/SaleItem Sync y habilita Productos, Nueva venta e Historial en Web/PWA sobre Supabase. El historial remoto consultado el 21/9/2026 registra las migraciones POS como aplicadas; falta la validación operativa real. Las demás entradas de navegación siguen siendo demostraciones sin datos de negocio, excepto Stock de Sprint 7.

El flujo prioritario de mostrador es escanear código → agregar producto existente o dar de alta uno desconocido → seguir escaneando → cobrar con una forma de pago → consultar venta. También admite productos sin código mediante alta manual y búsqueda por nombre. En Web móvil se usa búsqueda táctil; el input + Enter admite lectores HID en navegadores Desktop. Una venta completada conserva nombre y precio históricos. Desktop puede operar sin Internet; Web requiere Cloud.

Sprint 7 incorpora en código inventario por producto y sucursal en ambas plataformas. El producto puede controlar o no stock; los existentes quedan desactivados por defecto. Owner/admin establece stock inicial, registra entradas y ajusta al conteo físico; staff consulta y vende. Cada cambio no nulo de cantidad crea un movimiento inmutable y actualiza el balance. El POS muestra stock controlado y advierte cuando la cantidad excede la disponible, pero permite la venta y el balance negativo. Las ventas previas a esta infraestructura no descuentan stock. La migración Cloud de inventario está pendiente de aplicación; no se ha validado todavía el flujo completo con un usuario real.
