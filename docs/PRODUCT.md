# Producto

CentroColor será una aplicación operativa para un negocio de fotografía, marquetería y venta de productos. Gradualmente gestionará ventas, productos, stock, clientes, trabajos fotográficos, marquetería, turnos, sesiones, eventos, alquiler de recursos y equipamiento, presupuestos y pagos.

Los Sprints 1 y 2 entregan la fundación técnica y la identidad estructural de negocio, sucursal y dispositivo. Sprint 3 incorpora autenticación y autorización. Sprint 4 incorpora Clientes en Web y Desktop; su sincronización bidireccional ya existe. Sprint 5 incorpora POS MVP Desktop para cargar productos durante ventas y cobrar offline. Sprint 6 agrega en código ProductCategory/Product y Sale/SaleItem Sync y habilita Productos, Nueva venta e Historial en Web/PWA sobre Supabase. Su uso Cloud real requiere aplicar las migraciones POS pendientes. Las demás entradas de navegación siguen siendo demostraciones sin datos de negocio.

El flujo prioritario de mostrador es escanear código → agregar producto existente o dar de alta uno desconocido → seguir escaneando → cobrar con una forma de pago → consultar venta. También admite productos sin código mediante alta manual y búsqueda por nombre. En Web móvil se usa búsqueda táctil; el input + Enter admite lectores HID en navegadores Desktop. Una venta completada conserva nombre y precio históricos. El POS no gestiona stock, impresión fiscal ni pagos divididos. Desktop puede operar sin Internet; Web requiere Cloud.
